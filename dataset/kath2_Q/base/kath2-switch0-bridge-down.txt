==================================================
Scenario: kath2-switch0-bridge-down
Topology: Kath2
Fault family: L2 switch fabric down
==================================================

[PROMPT-TO-AGENT]
PCs in the IT Department (192.168.1.x) report they cannot reach
their gateway (192.168.1.1) or anything off-subnet. CS Dept PCs
(192.168.2.x) and all other zones are unaffected. Identify the
failure.

[INJECTION]
device: switch0
action: bring down the bridge that carries IT Dept LAN
cmd: ip link set br0 down

[POST-INJECT-CHECK]
switch0  ip -br link show br0 | grep -c UP   => expect 0
it_hod   ping -W2 -c2 192.168.1.1            => expect loss>0
cs_hod   ping -W2 -c2 192.168.2.1            => expect 0% loss (CS unaffected)

[GROUND-TRUTH]
Affected component: switch0 br0 (L2 fabric for IT Dept LAN)
Mechanism: switch0's br0 carries the IT Dept LAN's path to
  router0's 192.168.1.1 SVI. With br0 down, IT hosts lose their
  gateway and all off-subnet reachability. Other subnets are on
  different switches/bridges, so they're unaffected.
Localization: switch0
Root cause: br0 administratively down on switch0
Fix: `ip link set br0 up` on switch0

[FIX]
`ip link set br0 up` on switch0

[DIAGNOSTIC-PROCESS]
1. Scope the symptom: confirm that only IT Dept (192.168.1.x) hosts lose
   connectivity — including host-to-host and host-to-gateway — while CS Dept
   and all other zones are unaffected. The total L2 isolation of a single
   segment points to its switch fabric.
2. Layer 1/2 first: check bridge state on switch0 — run `ip -br link show br0`
   to find br0 is DOWN.
3. Confirm the scope: br0 is the only L2 fabric connecting IT Dept hosts to
   each other and to router0's 192.168.1.1 SVI. With br0 down all forwarding
   stops across every port in that bridge domain.
4. Verify CS is on a different bridge: confirm CS Dept uses a separate switch/
   bridge (not br0 on switch0), explaining why it is unaffected.
5. Localize to switch0 br0: rule out a router0 interface failure by confirming
   router0's SVI/interface is up; the L2 bridge state is the lowest-layer cause.

[PROMPT-TO-AGENT]
102.1.2.0/24, 102.1.3.0/24, 102.1.4.0/24 disappeared from r1's
RIB but 102.1.1.0/24 is still there. R12's EIGRP adjacency
with R11 is still up. Find what selectively removed those three
prefixes.

[INJECTION]
device: r12
action: bring down the three dummy loopback interfaces hosting
  102.1.2/3/4

  ip link set lo1 down
  ip link set lo2 down
  ip link set lo3 down

[GROUND-TRUTH]
Affected component: r12 dummy interfaces lo1, lo2, lo3
Mechanism: r12's four /24 loopbacks live on separate Linux
  interfaces (lo, lo1, lo2, lo3) — that's the workaround for
  FRR eigrpd only advertising one prefix per interface. When
  lo1/lo2/lo3 go down, EIGRP withdraws those three prefixes;
  102.1.1.0/24 (on the real `lo`) stays advertised. R11
  withdraws them upstream into OSPF.
Localization: r12
Root cause: dummy interfaces lo1/lo2/lo3 are down on r12
Fix: `ip link set lo1 up; ip link set lo2 up; ip link set lo3 up`
  on r12

[FIX]
`ip link set lo1 up; ip link set lo2 up; ip link set lo3 up`
  on r12
